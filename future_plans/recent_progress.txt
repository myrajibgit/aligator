1. EXECUTIVE SUMMARY & PRODUCT VISION
================================================================================
StudyCompete is a gamified, mobile-first study platform designed for middle school,
high school, and college students. Unlike broad, impersonal study apps, StudyCompete
scopes community, chat, and leaderboards to a student's actual institute, class,
and local area.

Core Value Proposition:
- Duolingo-style daily academic & fitness habit loops.
- RPG-style progression (Knowledge Power, IQ, Battle IQ, Subject XP).
- Institute-scoped social networking (classmate DMs and 2-6 student study parties).
- Anti-cheat verified daily routines: Health sensor checks & physical textbook OCR.
- Inter-class & inter-school competitive ranked battles:
  * 3-Round asynchronous RPG stat duels.
  * Multi-tier ladders: Class, School, City/Area, and Weekly Elite.
  * Cross-School Scout unlock for top 10% academic performers.

3.11 PHASE 4 — COMPETITION LAYER (COMPLETED)
--------------------------------------------------------------------------------
1. Competition Data Models:
   - `lib/features/competition/models/battle_model.dart`:
     * `BattleRound`: roundNumber, statCategory, label, scoreA, scoreB, winnerUid.
     * `BattleModel`: challenger & challenged student profiles, schoolId, classId,
       rounds list, status (pending/accepted/completed/declined), winnerUid, timestamps.
   - `lib/features/competition/models/leaderboard_entry_model.dart`:
     * Rank, student name, handle, XP, Knowledge Power, IQ, Battle IQ, isCurrentUser badge.

2. Head-to-Head 3-Round Stat Duel Engine (`lib/features/competition/services/battle_service.dart`):
   - Asynchronous Stat Duel Model: Prevents real-time networking lag and scheduling friction.
   - Anti-Farming Rule: Enforces strict maximum of 2 battles against the same opponent per week.
   - 3-Round Resolution Mechanics:
     * Round 1 (Subject Duel): Picks a random common subject. Calculates probabilistic
       variance: P(Win) = Stat_A / (Stat_A + Stat_B).
     * Round 2 (IQ Duel): Compares quiz accuracy and IQ ratings with ±5% variance.
     * Round 3 (Knowledge Power Duel): Compares cumulative Knowledge Power ratings.
   - Rewards:
     * Winner: +100 XP and increments `stats.battleIQ` by 1.
     * Loser: +20 consolation XP (encourages active participation without demotivation).

3. Tiered Ranking Pyramid (`lib/features/competition/services/leaderboard_service.dart`):
   - Tier 1 (Class Rank): Real-time leaderboard within the student's class and stream.
   - Tier 2 (School & Area Rank): Compares top rankers of each class against other classes,
     and area/city-wide rankings across schools in the same municipality.
   - Tier 3 (Weekly Leaderboard): Periodic competitive ladders.
   - Cross-School Scout Status: Top 10% performers (or top 3 in cohorts < 20) dynamically
     unlock "Cross-School Scout" status, granting visibility into elite rival leaderboards
     and the ability to issue cross-school duel challenges.

4. UI & Interactive Screens:
   - `lib/features/competition/screens/competition_hub_screen.dart`:
     * Tab 1: Rankings & Leaderboards with filter chips (Class, School, Area, Weekly Elite),
       Top 3 podium display (🥇 Gold, 🥈 Silver, 🥉 Bronze), and current user highlight tile.
     * Tab 2: Head-to-Head Battles with Battle IQ card, Incoming Challenges with instant
       Accept/Decline actions, Sent Challenges, and Battle History.
   - `lib/features/competition/screens/battle_duel_screen.dart`:
     * High-energy RPG duel arena view with Challenger vs Challenged banner, round-by-round
       stat clash cards, animated balance bars, and victory fanfare ceremony.
   - `lib/features/competition/screens/new_challenge_screen.dart`:
     * Classmate selector and Cross-School Rival selector (locked unless Scout status active).
     * Live anti-farming counter ("Battles this week: X/2").
   - `lib/shared/router/app_router.dart`:
     * Replaced placeholder screen with `CompetitionHubScreen` on `/home/compete`.
     * Added child routes `/home/compete/duel/:battleId` and `/home/compete/new-challenge`.

5. Cloud Functions & Firestore Indexes:
   - `functions/src/triggers/onBattleCreated.ts`: Sends FCM push notifications to challenged students.

5. HOW TO RUN & TEST THE CURRENT APPLICATION
================================================================================
A. BUILD VIA GITHUB ACTIONS (RECOMMENDED):
   1. Double-click `studycompete/PUSH_TO_GITHUB.bat` (or run git commands in terminal).
   2. Enter your GitHub repository URL.
   3. GitHub Actions builds the APK automatically on push!
   4. Download `studycompete-android-apk` from the Actions tab.

B. LOCAL WORKSTATION (IF FLUTTER INSTALLED):
   1. Install Dart dependencies:
      cd studycompete
      flutter pub get
   2. Run code generation:
      dart run build_runner build --delete-conflicting-outputs
   3. Run unit tests:
      flutter test
   4. Run app:
      flutter run
